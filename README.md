## 📌 Description
This project is part of CS213: Object-Oriented Programming Assignment 1  
It implements an image processing tool in *C++* using OOP concepts.  

The program allows the user to:
- Load an image (JPG, PNG, BMP…etc)
- Apply different filters (Grayscale, Invert, Merge, Rotate, Frame, …etc)
- Save the result with a new name or overwrite the original file
- Display a continuous menu until the user exits


## 📌 Filters Implemented
- Filter 1: Grayscale Conversion
- Filter 2: Black and White
- Filter 3: Invert Colors
- Filter 4: Merge Two Images
- Filter 5: Flip Image
- Filter 6: Rotate (90, 180, 270)
- Filter 7: Darken/Lighten
- Filter 8: Crop Images
- Filter 9: Adding a Frame to the Picture
- Filter 10: Detect Image Edges
- Filter 11: Resizing Images
- Filter 12: Blur Images
- Filter 13: Land Of Wano
- Filter 14: Oil Painting
- Filter 15: Wano
